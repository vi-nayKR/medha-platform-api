# Inactive operational workflow examples

These four files were moved out of `.github/workflows` for the public reference snapshot. GitHub Actions does not load workflow files from this directory.

They describe historical self-hosted builds, registry pushes, infrastructure-repository writes and release merges. They are **not** runnable public CI templates and must not be copied back unchanged. Their relative reusable-workflow paths are intentionally not active here.

Any future deployment automation belongs in the authorized operational source, with explicit ownership, environment approvals, minimal secret contracts, trusted refs/runners and a reviewed target repository. Do not connect this public derivative to production secrets.

See [publication review](../PUBLICATION_REVIEW.md). No private product workflow was modified.
